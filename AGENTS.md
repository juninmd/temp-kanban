# AGENTS.md - Temp Kanban (KanbanFlow)

- **Language:** TypeScript
- **Frontend:** React 18
- **Build:** Vite
- **Styling:** TailwindCSS
- **Drag & Drop:** dnd-kit
- **State:** Zustand
- **Linting:** ESLint

## Project Structure
```
src/              # React source code
```

- `pnpm dev` — Start dev server

- `pnpm lint` — Lint with ESLint
